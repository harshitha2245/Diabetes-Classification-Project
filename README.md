# Diabetes Classification Project

## Project Overview
This project predicts whether a patient has diabetes using Machine Learning algorithms.

## Dataset
- Source: Kaggle Diabetes Prediction Dataset
- Features:
  - Gender
  - Age
  - Hypertension
  - Heart Disease
  - Smoking History
  - BMI
  - HbA1c Level
  - Blood Glucose Level

## Project Workflow
1. Data Loading
2. Data Exploration (EDA)
3. Data Cleaning
4. Feature Encoding
5. Train-Test Split
6. Model Training
   - Logistic Regression
   - Decision Tree
   - Random Forest
7. Model Evaluation
   - Accuracy
   - Precision
   - Recall
   - F1 Score
   - ROC-AUC
   - Confusion Matrix

## Best Model
Random Forest achieved the best overall performance.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Kaggle Notebook

## Results
The Random Forest model provided the highest accuracy and balanced performance for diabetes prediction.
